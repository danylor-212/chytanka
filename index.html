Читанка

Українська прошивка для електронних читалок Xteink X4 і X3 — на основі CrossInk і CrossPoint.

версія 1.6.0.2

Встановлення

Цей браузер не вміє працювати з USB-портами (Web Serial). Відкрийте сторінку в Chrome, Edge або Opera на комп'ютері. Телефони й планшети не підходять. Встановлення працює лише через HTTPS. Відкрийте danylor-212.github.io/chytanka.

Налаштування, статистика, Wi‑Fi і книжки на SD-картці не стираються. У вікні «Erase device» залиште галочку знятою.

Читанка — це CrossInk з українським інтерфейсом, правильними переносами, цитатами української літератури на заставці та вбудованим каталогом безкоштовних книжок. Детальніше — у репозиторії і примітках до релізу.

Що потрібно

Пристрій

Xteink X4 або Xteink X3 (одна прошивка для обох). X4 Pro, X4 Classic та інші читалки не підтримуються.

Браузер

Chrome, Edge або Opera на комп'ютері (Windows, macOS, Linux) — з підтримкою Web Serial. Safari і браузери на телефонах не підійдуть.

Кабель

USB-C кабель з передаванням даних, не лише для заряджання. Краще підключати напряму в комп'ютер, без хаба.

Linux

Порт /dev/ttyACM0 зазвичай належить групі dialout (в Arch — uucp): sudo usermod -aG dialout $USER, потім вийдіть із сеансу й зайдіть знову.

Спершу — бекап (рекомендовано)

Браузерний інсталятор не вміє робити копію пам'яті пристрою. Якщо хочете мати змогу повернути все як було, зробіть повний бекап через esptool (≈2 хвилини):

pipx install esptool
esptool --chip esp32c3 --port /dev/ttyACM0 --baud 921600 read-flash 0 ALL x4-backup.bin

У Windows порт називається COM3, COM4… (див. Диспетчер пристроїв), у macOS — /dev/cu.usbmodem…. У бекапі є збережені паролі Wi‑Fi — не викладайте його в інтернет.

Як встановити

  1. Увімкніть читалку й залиште її на головному екрані. Вона має бути ввімкнена й не спати, поки йде прошивка.
  2. Підключіть її USB-кабелем до комп'ютера.
  3. Натисніть «Встановити Читанку» вище.
  4. У списку портів виберіть «USB JTAG/serial debug unit» (у Windows — «USB Serial Device (COMx)»; ідентифікатор виробника 303a) і натисніть «Підключитися» / «Connect».
  5. Натисніть «Install Читанка…». У вікні «Erase device» не ставте галочку — тоді налаштування й дані збережуться — і натисніть «Next», потім «Install».
  6. Зачекайте 1–3 хвилини, поки індикатор дійде до кінця. Не від'єднуйте кабель і не закривайте вкладку.
  7. Перезапуск. Якщо читалка не перезапустилася сама, від'єднайте й знову під'єднайте кабель, коротко натисніть кнопку Reset і одразу затисніть кнопку живлення на 3–5 секунд. З'явиться екран Читанки з написом «версія 1.6.0.2-ua».

Якщо порт не з'являється або підключення не вдається

  • Розбудіть пристрій. Він має бути на головному екрані, а не в режимі сну. Спробуйте ще раз після того, як екран оновився.
  • Інший кабель або порт. Найчастіша причина — кабель лише для заряджання. Спробуйте інший USB-порт, без хаба.
  • Закрийте інші програми, які можуть тримати порт: інші вкладки з прошивальниками (Inky, CrossPoint), Arduino/PlatformIO-монітор, screen, minicom. Порт може відкрити тільки одна програма.
  • Linux: перевірте групу dialout (див. вище) і dmesg | tail — там має з'явитися ttyACM0.
  • Завислий пристрій: натисніть Reset, потім затисніть кнопку живлення, щоб він завантажився, і спробуйте знову.
  • Повідомлення інсталятора «hold the BOOT button» до Xteink не стосується: окремої кнопки BOOT немає, а прошивка йде через вбудований USB-порт працюючого пристрою.

Пристрій так і не з'являється у списку? Можливо, у нього заблоковане прошивання через USB. Таке буває з читалками, купленими не на xteink.com (наприклад, на AliExpress). Для них розробники CrossPoint зробили Xteink Unlocker. За їхніми словами, офіційно він підтримує лише CrossPoint і CrossInk, а будь-яка інша прошивка на заблокованому пристрої може його остаточно зіпсувати. Тому Читанку через Unlocker напряму не ставте. Спершу встановіть через нього CrossInk, а потім оновіться до Читанки з SD-картки (див. нижче).

Після встановлення

  • Вітальний екран. Якщо раніше стояв CrossInk або CrossPoint з іншою мовою чи налаштуваннями, Читанка один раз запропонує перемкнути інтерфейс на українську й увімкнути рекомендовані налаштування читання. «Пізніше» нічого не змінює. Мову можна змінити й пізніше: Налаштування → Система → Пристрій → Мова (Settings → System → Device → Language).
  • Згладжування. Читанка радить вимкнути його: текст стає чіткішим, а сторінки гортаються за одне оновлення екрана. Якщо налаштування лишилися від попередньої прошивки, вимкніть вручну: Налаштування → Читання → Параметри шрифту → Згладжування тексту.
  • Книжки. Каталог «Читанка — Книжки» вже є в списку OPDS: безкоштовна українська класика, завантаження по Wi‑Fi.
  • Словники й шрифти. Українсько-англійський і англійсько-український словники Вікісловника: chytanka-dicts (розпакуйте в /.dictionaries/ і виберіть «Вікісловник укр-англ» у Налаштування → Читання → Словник). 16 шрифтів з повною українською абеткою: Налаштування → Читання → Параметри шрифту → Завантажити шрифти.
  • Обкладинки один раз перегенеруються, а книжки під час першого відкриття можуть заново розбитися на сторінки — це нормально.

Оновлення

Далі Читанка оновлюється сама, по повітрю: Налаштування → Система → Перевірити оновлення. Нові версії беруться тільки з релізів Читанки, тож стоковий CrossInk її не замінить.

Без комп'ютера: завантажте firmware-x3-x4.bin з останнього релізу, покладіть на SD-картку й виберіть Налаштування → Система → Оновлення прошивки з SD-картки. Цей пункт є і в CrossInk (Settings → System → SD Card Firmware Update).

Відкат

  • З бекапу: esptool --chip esp32c3 --port /dev/ttyACM0 --baud 921600 write-flash 0 x4-backup.bin
  • На стоковий CrossInk: прошийте його з inky.crossink.dev.

Вручну: esptool-js або термінал

Якщо кнопка вище не спрацювала, те саме можна зробити в esptool-js (теж у браузері) або в esptool. Завантажте чотири файли (посилання в таблиці або з релізу) і вкажіть адреси:

АдресаФайлЩо це
0x0bootloader.binзавантажувач
0x8000partitions.binтаблиця розділів
0xe000boot_app0.binвибір розділу, з якого завантажуватися
0x10000firmware-x3-x4.binсама Читанка

У esptool-js: Baudrate 921600 → Connect → додайте чотири рядки «Flash Address + файл» → Program. Кнопку Erase Flash не натискайте: вона зітре налаштування. Контрольні суми — у SHA256SUMS. Попередні версії лежать у firmware/v…/ (наприклад, v1.6.0.1) і в релізах.

esptool --chip esp32c3 --port /dev/ttyACM0 --baud 921600 write-flash \
  0x0 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware-x3-x4.bin

In English

Chytanka is a Ukrainian edition of CrossInk firmware for the Xteink X4 and X3. Use desktop Chrome, Edge or Opera and a USB data cable. Keep the reader awake on its home screen, click «Встановити Читанку», pick “USB JTAG/serial debug unit” (VID 303a) and leave Erase device unchecked so your settings survive. Then unplug and replug, press Reset and hold Power. The installer writes the bootloader (0x0), partition table (0x8000), boot_app0 (0xe000) and the app (0x10000) and leaves NVS and data partitions alone. It can't make a backup, so run esptool read-flash 0 ALL backup.bin first if you want one. If the port never shows up, the device may be USB-locked. The CrossPoint Unlocker officially supports only CrossPoint and CrossInk, so install CrossInk with it first and then update to Chytanka from the SD card. Later updates arrive over the air from Chytanka releases.
